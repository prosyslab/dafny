# Compute recursive modifies frames and narrow cache invalidation

Status: done, 2026-11-22. The user approved planning and implementation.

## Goal

Infer stable write frames across self-recursive and mutually recursive methods. Use strongly connected components (SCCs) of the candidate method-call graph to process dependencies before callers. Compute the least fixed point within each recursive component. Keep resolution-cache entries for modules unaffected by changes to the set of source files eligible for CLI inference.

The Dafny checkout owns all changes. This affects resolution, inferred specifications, the proofs that consume them, and language-server resolution caching. The benchmark repository, evaluator, scoring, deployed binaries, and explicit contract syntax are outside scope. No paid runs are needed.

## Existing code and compatibility

`InferModifiesClause` walks resolved statements, instantiates normal callee frames, preserves source syntax, and deduplicates targets. Its active-stack cycle detection can classify different methods as recursive when overlapping cycles are traversed in different orders. `Graph<T>` already computes SCCs. The general module call graph includes additional edge kinds, so the effect graph must use the resolved statement calls that inference consumes. `CachingResolver.GetHash` already includes dependency hashes. It currently salts every key with the same full-program source set. Source methods in the default module can have several distinct file origins.

Maintain both `--inferModifies` and `{:inferModifies}`, using normal verifier checks on all materialized frames. Keep explicit frames, extern contracts, and unsupported implicit callee fallback. Collect unsupported implicit members per iteration, drop them together, and recompute the remaining component using their original contracts. Report explicit failures that remain after implicit fallback. This avoids letting traversal order select which recursive member loses inference. Recursive transfer over constant fields can grow paths indefinitely. Independent review reproduced exponential work when unrelated scalar arguments inflated the initial depth guard in a two-branch recursion. Detect reachable path-growing cycles from the actual frame roots before enumerating their frames, retain a structural termination guard, and leave the original contracts on growth. Never publish a partial recursive result. Use the direct ordered transfer path for acyclic methods.
