# Inferred modifies for fixed heap locations

`{:inferModifies}` asks Dafny to synthesize a normal `modifies` clause for an ordinary method. The pass in [InferModifiesClause.cs](../Source/DafnyCore/Resolver/InferModifiesClause.cs) collects heap assignments and instantiated callee frames. The verifier uses the resulting frame for the method body, for calls, and for preservation outside the frame. See the [language reference](../docs/DafnyRef/Attributes.md#sec-attr-infer-modifies) for usage and the [implementation plan](../plan/2026-11-22-infer-modifies.md) for verification details.

The pass runs after name resolution and before export checking. An inferred frame carries both a resolved expression and source-shaped syntax. This matters because the export checker clones contracts and resolves them again with fewer names in scope. A frame that mentions a member hidden by an export set fails the same consistency check as a handwritten frame. C# source embedding prints a materialized contract. The `.doo` backend stores a parse snapshot with CLI-inferred frames copied onto their source declarations. An attribute-requested frame can still be re-inferred from that snapshot.

The supported paths start at `this` or an input and may follow constant fields. The pass rejects mutable reference paths and allocation. A declared frame can serve as a summary at a recursive call boundary. A bodyless or external callee uses its declared contract. Scope validity and the usual proof checks still apply to the generated frame.

Verified on 2026-11-22 in the native `expecto` worktree at `a9dd0480d` plus the edits in the plan. A [temporary proof with the actual BenchIO model](../../tmp/infer-modifies/bench-io.dfy) verified all three wrappers and proved stdin preservation across `Flush`. The [IO regression](../Source/IntegrationTests/TestFiles/LitTests/LitTest/dafny0/infer-modifies-io.dfy) additionally checks composition through an export set. Nine affected Lit cases and the `.doo` and embedded C# source round trips passed. Benchmark source policy and installed tool selection are outside this change.

`--inferModifies` enables inference for eligible source methods with omitted frames while retaining `{:inferModifies}` for individual requests. Unannotated unsupported methods use their original contracts. Already-verified imports keep theirs. Archived programs built with the flag were verified by consumers with the flag off. The original CLI changes were checked on seven feature Lit cases and a wrapper around the actual BenchIO model. [CLI plan and verification record](../plan/2026-11-22-infer-modifies-cli.md)

## Recursive frames and module caching

The resolver processes strongly connected components of eligible methods and uses a worklist to propagate newly discovered frames between recursive callers. A component publishes its inferred contracts once the worklist reaches a fixed point. A recursive call that permutes inputs or set-display elements can reach a fixed point. Set-display equality ignores order and repeated elements. [Resolver](../Source/DafnyCore/Resolver/InferModifiesClause.cs)

A recursive substitution can add a constant-field projection to a write target on each call. The resolver detects reachable growth cycles from the roots of seeded frames before enumerating their effects. For growth it keeps the original contracts for the entire component and reports explicit requests that failed. For unsupported substitutions it removes failed implicit members together and retries the remaining components before reporting any explicit failures. The ordinary verifier checks every frame after inference. [SCC and cache plan](../plan/2026-11-22-infer-modifies-scc-cache.md)

For CLI inference the resolution key reflects verified-source membership of local method origins. The shared default module can hold methods from several files. Nested modules and importers receive key changes through the existing dependency hashes. [Caching resolver](../Source/DafnyLanguageServer/Language/CachingResolver.cs)

Verified on 2026-11-22 at `a9dd0480d` with the inferred-modifies working-tree changes. Nine Lit fixtures, two in-memory cache tests, and a recursive `.doo` round trip passed. Independent probes confirmed an empty contract on path growth, one frame for permuted eight-element sets, and matching frames across declaration orders. [Verification record](../plan/2026-11-22-infer-modifies-scc-cache.md#verification-record)
